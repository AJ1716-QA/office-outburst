# OFFICE OUTBURST

An original 3D cartoon office action-comedy game prototype.

## Current prototype

- Third-person 3D office scene powered by Three.js
- Keyboard movement (WASD / arrow keys)
- Mouse-drag camera turning
- Mobile virtual joystick
- Paper-ball throwing and target scoring
- Rage meter, taunt button, direct-hit counter, and five-hit mission completion
- Mobile joystick input separated from camera-drag input, plus a throw cooldown
- PWA manifest, custom SVG app icon, and lightweight service worker shell cache (the 3D engine still needs internet)

## Run locally

Serve this folder with any static web server, then open the page in a modern browser. Three.js is loaded from jsDelivr, so an internet connection is required.

## Controls

- WASD / arrow keys: move
- Drag mouse: turn camera
- Space: throw a paper ball
- Escape: pause
- Mobile: joystick and on-screen buttons
